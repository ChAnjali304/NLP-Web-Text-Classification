\# Natural Language Processing Classification of Web Texts Combined with Deep Learning



\## Project Overview



This project focuses on the classification of web texts using Natural Language Processing (NLP) and deep learning techniques.



\## Technologies Used



\- Python 3.11.9

\- Django

\- MySQL 8.0

\- HTML

\- CSS

\- JavaScript

\- Bootstrap



\## Model Architecture



The project report describes a BERT-based architecture consisting of:



\- BERT contextual embeddings

\- Bidirectional GRU (BiGRU)

\- Convolutional Neural Network (CNN)

\- Attention mechanism

\- Feature concatenation

\- Linear layer

\- Softmax classification output



\## Features



\- Single text classification

\- Batch text classification

\- Text file upload and processing

\- Classification model selection

\- Predicted category and confidence display

\- Keyword display

\- Saving and downloading results



\## Classification Models



\- BERT-BGCA Classifier

\- OpenAI Classifier

\- Model Ensemble



\## Dataset Categories



\- News

\- Social media

\- Reviews

\- Spam

\- Blogs

\- Cybersecurity

\- Educational text



\## Reported Results



According to the project report:



\- Accuracy: 95.21%

\- F1-score: 94.36%



These results are reported figures and have not been independently verified.
