\# System Architecture



\## Project Overview



Natural Language Processing Classification of Web Texts Combined with Deep Learning.



The system is designed to classify web text using NLP and deep learning techniques.



\## Model Architecture



The project report describes a BERT-based architecture with the following components:



1\. BERT contextual embeddings

2\. Bidirectional GRU (BiGRU) path

3\. Convolutional Neural Network (CNN) path

4\. Attention mechanism

5\. Feature concatenation

6\. Linear layer

7\. Softmax classification output



\## Application Technologies

\- MySQL 8.0

\- HTML

\## Application Features



\- Classify a single text input

\- Classify multiple texts in a batch

\- Upload text files for classification

\- Select a classification model

\- Display predicted category and confidence

\- Display keywords

\- Save or download classification results
