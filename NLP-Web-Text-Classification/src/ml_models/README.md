\# Machine Learning Models



This directory is intended to contain the machine-learning model implementations used in the project.



\## Models Described in the Project Report



\### 1. BERT-BGCA Classifier



The report describes a BERT-based architecture that combines contextual embeddings with parallel BiGRU and CNN paths, an attention mechanism, feature concatenation, a linear layer, and Softmax classification.



\### 2. OpenAI Classifier



The report lists an OpenAI-based classification option.



\### 3. Model Ensemble



The report lists an ensemble classification option that is intended to combine model predictions.



\## Related Components



The report also refers to model utilities and classification-related classes.



\## Implementation Status



This README documents the models mentioned in the report. It does not contain their Python implementations. Add the actual model source files when they have been located or implemented and tested.
